# Founder brand

1. Read the user’s brief and relevant existing `founder/idea.md`, `marketing.md`, `competitors.md` and `panel/results.md`. Missing positioning is a labelled hypothesis, not a prerequisite to run another project.
2. For naming: propose distinct candidates, explain meaning/pronunciation/use risks, and shortlist three. For each shortlist, check the market’s official trademark register, domains, handles and competitor confusion. Link and date public checks; mark unavailable checks. Availability is not legal clearance or registration.
3. For voice: give one promise, three tagline options, and three voice traits with do/don’t examples. Rewrite one existing pitch line to demonstrate them.
4. For a visual brief: give 2–3 colors with hex values and WCAG AA text-contrast checks; licensed/free display and body fonts; logo requirements and uses; first touchpoints (homepage/sign, packaging, receipt, social post, complaint reply). Follow user-specified brand choices.
5. Write only the requested sections to `founder/brand.md`. If the user requests the whole brand, include all sections. Generate images only on an explicit image-generation request; label concepts as concepts. Do not copy competitor identities or use unlicensed assets.

Done: the brief answers the requested scope, names sources/check dates, and separates confirmed facts from provisional choices. State any unverified availability or contrast check. Nothing is registered, purchased or published by producing this brief.
